# Roadmap

## Phase 0 — Foundation
- Brand/design system
- org + user model
- document upload
- source provenance
- module registry
- demo dashboard

## Phase 1 — Real freight/AP MVP
- freight invoice + rate sheet + BOL extraction
- normalized invoice lines
- deterministic comparison rules
- evidence panel
- PDF/CSV Recovery Report export
- manual approval + claim draft

## Phase 2 — SaaS / AI Spend
- seat/usage imports
- inactive seat and overlap findings
- AI usage anomaly rules
- contract price checks

## Phase 3 — Recovery Operating System
- case pipeline
- vendor communications log
- approvals
- realized savings ledger
- alerts

## Phase 4 — Connectors
Prioritize by customers: QuickBooks/NetSuite, major parcel carriers, major cloud/AI/SaaS providers, Stripe, telecom and 3PL exports.

## Phase 5 — Prevent Before Pay
- ERP/AP pre-payment checks
- renewal alerts
- approval gates
- recurring leakage rules

## Phase 6 — Enterprise
- SSO/SCIM
- SOC 2 program
- custom rules
- data warehouse exports
- advanced RBAC
- multi-entity/multi-currency

## Phase 7 — Network Intelligence
- privacy-safe benchmarks
- vendor/rate intelligence
- negotiation recommendations
- outcome-based recovery playbooks

## Billion-dollar discipline
Do not chase every vertical simultaneously. Build the common engine, prove ROI in 1–2 wedges, and add modules only when they reuse the engine or unlock a distribution channel.
